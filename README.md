# tel-jay-site

Public pages for the Tel-Jay app, served by GitHub Pages at https://jayridge.github.io/tel-jay-site/.

- `privacy.html`: the privacy policy, the URL given to TestFlight and the App Store. Its source is
  `Apps/TelJay/Store/privacy.html` in the (private) Tel-Jay repository; change it there and copy it here.
- `index.html`: a landing page that links to it.
